# Spotlight (⌘K)

How to find and start everything in Axiomata with ⌘K: commands, tiles, skills, routines, cards, plans, projects, tags and files — and how to ask the chat from there.

## What it is

Spotlight is the search field above everything that offers “Search, or ask Axiomata …”. It searches the whole app
at once and with Enter directly carries out what it found. Without input it shows “Jump to”: “New note”,
“Open Kanban”, “Open Studio”, “Open Second Brain”, “Settings”.

## Where the buttons are

- **Open:** ⌘K (Windows/Linux: Ctrl+K) or the magnifier “Search or run” in the dock. ⌘K again, Esc or a click
  beside it closes.
- **The groups and what Enter does:**
  - **Commands** — “New note”, “Settings”, “Open Kanban”, “Open Studio”, “Add module”, “Open Second Brain”: runs
    the command.
  - **Modules** — puts the tile on the canvas (single tiles already placed are missing here).
  - **Skills** — runs the skill; the result comes as a notice at the bottom right.
  - **Routines** — shows or places the “Routines” tile.
  - **Cards** — opens the card in the Kanban.
  - **Plans** — opens the Studio in “Flow” mode.
  - **Projects** — opens the Studio on this project.
  - **Tags** — opens the Second Brain, filtered to the tag.
  - **Files** — by name and, from two characters on, in the full text; Enter opens the file in the file window,
    ⌘Enter shows it in the Second Brain instead.
  - **Ask** — “Ask Axiomata” always comes last and sends the input to the chat.
- ↑/↓ select, Enter or a double click carries out.

## Common tasks

1. **Open a file:** ⌘K → a few letters of the name → Enter.
2. **Run a skill:** ⌘K → skill name → Enter.
3. **Ask something:** ⌘K → type the question → “Ask Axiomata” at the very bottom → Enter.

## Traps

- Enter on a skill **runs** it at once — a real agent turn that can cost money.
- ↑/↓ only select; only Enter or a double click carries out.
- The full-text search searches the vault; files of a Studio project are found with ⌘P or ⇧⌘F in the Studio.
